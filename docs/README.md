# Документация backend

`backend` — NestJS + TypeORM приложение, которое генерирует сцену видео по паре «сценарий + коллекция
персонажей»: сначала текстовым промптом описывает изображение сцены, генерирует его через xAI Grok Imagine,
загружает в S3-совместимое хранилище, а затем оживляет изображение в короткое видео через того же
провайдера. Отдельно приложение умеет создавать персонажей и коллекции персонажей, которые служат
референсами для сцены.

Проект на ранней стадии: часть модулей (например, `GenerationItemModule`) — заготовки под будущий
асинхронный конвейер, реальный путь генерации сейчас синхронный.
